# Artifact and Data Availability

## Public package

This repository contains the publication text, high-level evaluation
description, citations, and checks for maintaining this publication boundary.
It does not include the EPC implementation, executable builds, internal
formats, detailed configuration, or raw benchmark files.

## Evaluation evidence

The manuscript reports the bounded outcome of a ten-process replay test and
measurements from three synthetic workloads on one x64 host. The public
package does not contain the test harness, workload definitions, per-run
observations, or environment-specific raw records. As a result, readers
cannot independently rerun the study using this repository.

## Reproduction status

The paper is an evidence-bounded report, not a public artifact-evaluation
release. Availability of implementation or raw data is not implied. Any
future release requires a separate rights, security, and disclosure review.
