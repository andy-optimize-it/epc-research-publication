# Security Policy

This repository contains publication material and no EPC runtime or
executable artifact.

Do not report sensitive vulnerability details in a public issue. Use GitHub's
private vulnerability reporting feature if it is enabled for the repository;
otherwise contact the repository owner through an already established private
channel. Do not include credentials, personal data, customer data, or
implementation details in a report to this publication repository.

The repository owner should review reports privately and avoid publishing
details that could expose the non-public implementation.
