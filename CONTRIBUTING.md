# Contributing

Contributions are limited to publication text, references, and repository
maintenance. This repository is not the EPC source repository and must not be
used to publish implementation material.

Before opening a pull request:

- Read [`IP.md`](IP.md) and preserve its publication boundary.
- Do not add source code, binaries, internal formats, detailed settings, raw
  measurements, confidential information, or third-party material without
  written clearance.
- Keep claims traceable to approved evidence and state limitations alongside
  results.
- Run `npm test` and include a concise description of the editorial change.

Submitting a contribution does not grant a license to the EPC implementation
or change the rights notice in [`LICENSE`](LICENSE).
